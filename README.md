**Smart India Hackathon (SIH) 2026**
**Team:** AquaScan
**PS ID:** 26064
**Theme:** Disaster Management

## Overview
AquaScan is a low-cost, deployable seafloor metal detection sensor and autonomous underwater vehicle (AUV) designed for ocean resource exploration. 

### Why Disaster Management?
The AUV is highly suited for disaster management because it helps:
- Detect underwater metallic hazards
- Locate submerged debris
- Support search & recovery operations
- Improve coastal safety
